# HCG — source manifest

**Study:** HCG (key `hcg`). **Kept by:** the HCG owner sessions. **Status:** working record; it changes by commit until the first HCG release.

This manifest lists every original HCG source file brought into `rtg-sat`, where it came from, its SHA-256, and where it has been placed. A row certifies **byte identity only**. It does not certify scientific correctness, authorship or publication rights.

The file table (§5) is generated by `evidence/hcg/verification/make_source_manifest.py` from `upload/hcg/SHA256SUMS`. The script recomputes every hash before writing a row. This head (§§1–4) is kept by hand in `records/hcg/HCG_SOURCE_MANIFEST_HEAD.md`.
