## 2. Reciprocal-locality corollary — CHECKED, with a scope sharpening

**Proof, re-derived.** For h₀-unitary g:
- E_{g⁻¹} = g⁻¹E_g = E_g, so a(g⁻¹) = a(g) in a common basis.
- (1 − g⁻¹)|_E is the h₀-adjoint of (1 − g)|_E, so b(g⁻¹) = conj b(g).
- Hence a(g)b(g)·a(g⁻¹)b(g⁻¹) = a(g)² N(b(g)), which is a norm. Pairing all indices leaves [(−1)ⁿ] = [1] for n = 4. ✓

**Sharpening.** The pairing must be by conjugacy under a **K-linear h₀-isometry**, for example Γ-conjugacy, which is what Hurwitz data provide. Conjugacy over C alone is not enough, because the local datum includes the Hermitian form on E_g (locality proof, §1: "the restricted coefficient Hermitian form is part of the local datum").
- *Control:* in K² with h₀ = diag(1, 2), the two order-2 reflections in the coordinate lines are C-conjugate and self-inverse. They give local factors 2 and 4, and class **[2]**.

**Exact test** (`reciprocity_check_claude.py`):
- 40/40 random K-unitary g (dimension 2–3, diagonal h₀ with non-norm entries) satisfy b(g⁻¹) = conj b(g) exactly and [a(g)a(g⁻¹)] = [1].
- 40/40 K-isometric conjugates u g⁻¹ u⁻¹ give a norm.

**Refinement (Claude).** With Γ-classes C of multiplicity m_C, the class depends only on the **inverse imbalance**:
- a self-inverse class has rational Δ(C) (because b = b̄), and only m_C mod 2 matters;
- a pair C ≠ C⁻¹ contributes Δ(C)^{m_C − m_{C⁻¹}}.

**Controls, re-derived.**
- C₆: (1 − ω)⁵(1 − ω²)³·2·(1 − ζ̄₆) = 162 by hand, giving [2]. ✓
- C₃ and G₃₄: both split. ✓

**Inert-prime criterion — CHECKED.** For D > 0, [D] = [1] iff v_p(D) is even for every p ≡ 2 (mod 3).
- Split primes impose no condition.
- The ramified place 3 follows from the Hilbert product formula.
- Positivity is automatic here, since signature (4, 4) gives a positive determinant.
- Brute force: for D ≤ 3000 the criterion agrees with integral representability by x² − xy + y².

## 3. Factorwise 2 ⊗ b, the S_{b+1} branch: three-active reduction CHECKED, plus three gates and a scan

**ChatGPT §4, re-derived.**
- t = 3: four actives cost 4b + 30 > 4b + 8.
- Every inactive A′ = I: μ ≠ 1 would cost ≥ b − 1, and 4b + 29 > 4b + 8.
- So A′(Γ) is generated by three elements with product I. ✓

Moreover an inactive costs **exactly 2·ind(w)**, because rank(1 − std w) = ind w.

**Gates added (Claude, PROPOSED).**
- **(E) Euler.** A′ is an irreducible rank-2 local system on P¹ minus 3 points, so dim H¹_par = Σ rank(1 − A′_i) − 4 ≥ 0. Hence not all three A′_i are reflections.
  - This is a third proof of the U(2) three-reflection step.
  - The same count for the std(w) factor is exactly Riemann–Hurwitz.
- **(Di) Dihedral.** If two actives have eigenvalues {1, −1}, they generate A′(Γ) as a dihedral group. Its character is real, so χ_V is real and Q(χ_V) ≠ K. This generalizes ChatGPT's 31–34 argument and subsumes the all-three determinant parity.
- **(RH-parity).** Σ ind = 2b + 2g′ is even.

**Exact scan** (`two_by_b_certificate_claude.py`, all cycle types of S_{b+1}, all cost distributions, all gates).
- **0 surviving patterns for every 24 ≤ b ≤ 58.**
- With (E) and (Di) switched off, the survivors reproduce ChatGPT's description: all-{1, −1} patterns at even b, and (b, b, 2b − 24) with types ({1, −1}, {1, −1}, refl) at b = 31 and 33.
- **At b = 59 one pattern survives:** costs (59, 75, 78), types ({1, −1}, refl, gen).
- **With the determinant gate** (`two_by_b_det_claude.py`): det A′₁·det A′₂·det A′₃ = 1, tracked exactly; "free" when a pair member is not an eigenvalue of std(w). The options are aggregated independently of the first scan.
  - Control without the gate: the same single b = 59 survivor, with determinants (−1, ω, 1), exactly as predicted by hand in step 5 of the analytic reduction below.
  - With the gate: **0 surviving patterns for every 24 ≤ b ≤ 64.**

**Analytic reduction for all b (Claude, PROPOSED).** Put out_i = c_i − b and e_i = (b + 2 + out_i)/2 − ind_i.
1. **Budget and Riemann–Hurwitz.** These give Σout_i ≤ b − 24 and Σe_i ≤ 7, with e_i ≥ 0.
2. **Lower bounds on out.** For a "gen" active (1 not an A′-eigenvalue), each cycle contributes ≥ ℓ/3, so out ≥ (b + 1)/3 − 1. For a "refl" active with f fixed points, out ≥ (b + 1 − f)/3, with f ≤ 2e − 1.
3. **Patterns closed for every b:**
   - (gen, gen, gen): Σout ≥ b − 2;
   - (gen, gen, refl): Σout ≥ b − 16/3;
   - (gen, refl, refl): Σout ≥ b − 4.

   Each exceeds b − 24. Every other pattern dies by (Di) or (E), except two.
4. **The two remaining patterns:**
   - ({1, −1}, refl, gen), possible only for b ≥ 58 (the b = 59 survivor);
   - ({1, −1}, gen, gen), possible only for b ≥ 68.
5. **Determinant.** When the gen active has L = lcm(ord x, ord y) = 3, its pair is {ω, ω²} and det = 1. Then the determinant product kills both patterns: ({1, −1}, refl, gen) would need y = −1, i.e. a second {1, −1}; ({1, −1}, gen, gen) gives (−1)·1·1 ≠ 1.
6. **What is left.** A gen active with L ≥ 4 has out ≥ (b + 1)/2 − 1. The crude thresholds are then b ≳ 117 and b ≳ 137; these are indicative only, not claimed.

**Scope.** This closes the S_{b+1} branch only. The full 2 ⊗ b also needs the block-system branches of the W-reduction. At d = 2b ≥ 60 these meet the imprimitive frontier, where Lemma B′ ends at r = 29.

## 4. Lemma T′ (Euler–Katz count for any factorwise tensor) — new, PROPOSED

**Statement.** Let V = A ⊗ B, a = dim A. Normalise the lifts of the A-parts:
- inactive branches (A-scalar) → I;
- actives → free scalar multiples, except one active, which absorbs the product scalar.

This is a genuine rank-a local system on P¹ minus the t active points. It is irreducible because the projective A-image is, so dim H¹_par = Σ rank(1 − A_s) − 2a ≥ 0. Put the largest eigenspace at eigenvalue 1 on every active except the one with the largest δ_i = a − m_i. This gives

  **Σδ_i − max δ_i ≥ a**  (Lemma T had only Σδ_i ≥ a).

Costs are as before: active c ≥ bδ_i, inactive c ≥ max(a, 2), N ≥ 19 and Σc = 2ab + 8.
