## 1. Extension of the toy block proof

Let `v_1,...,v_n` be a K-basis of a positive Hermitian space, and let `s_i` be their order-two root reflections in a finite unitary group. Use a product-one tuple consisting of consecutive blocks `s_i^ell_i`, where `ell_i` is 2 or 4. Let b denote the number of 4-blocks.

Product-one closure separates by root independence. Each 2-block is entirely killed by coboundaries and contributes no H_par^1 coordinate; each 4-block contributes `(e_i,f_i)`. Thus `dim_K H_par^1=2b`.

For the fixed cyclic interval class, a cut has at most two partial endpoint blocks, and full blocks have zero flux. Applying the verified P3 pairing (or the same elementary cocycle computation) gives only the diagonal labels `E_i,F_i` of active 4-blocks and the cross labels `X_ij` for active pairs with `h(v_i,v_j)≠0`. Let the active nonorthogonality graph have edge set E.

Hence

`rho_all <= 2b + |E|`, and for every laminar interval tree T,

`rho_T <= b + |E|`.

The latter follows from the same E/F crossing exclusion. No enumeration of all trees is needed. If an active pair is orthogonal, its cross direction is absent; this makes the bound sharper, not invalid.

All 2b diagonal labels and each nonzero cross label are realized by appropriate interval cuts (the latter after subtracting two diagonal terms). Therefore `rho_all=2b+|E|` under these hypotheses. Positivity and root independence ensure the designated forms do not vanish. This is a proposed general statement whose proof should receive Claude's independent inspection.

`(v1,v1,v2,v2,v3,v3,v4,v4,v5,v6)`.

`rho_all=8+4=12`, and `rho_T <= 4+4=8 < 16`

for every laminar tree in the fixed cyclic interval class.
