# HCG — Minimal d = 7 local-rank screen after the d = 6 obstruction

**Date:** 29 October 2026  
**Grade:** `[SESSION — ALG / PROPOSED]`; this is a new short deduction, not peer-reviewed or adopted.  
**Scope:** The same genus-zero nonsplit-eightfold feasibility screen: irreducible finite coefficient representation with character field K = Q(sqrt(-3)), no common fixed vector, parabolic dimension 8, at least 19 **effective** branch points, and the inherited exclusion of monomial representations. No group or algebraic family satisfying all gates is constructed here.

## 1. Seven combinatorial possibilities

Write c_j = rank_K(1-g_j) >= 1 for every effective branch point. With coefficient dimension d,

    sum c_j = 2d + 8,    N >= 19,
    epsilon = sum(c_j-1) = 2d+8-N <= 2d-11.

In particular, epsilon <= 3 holds **only at d=7**, not uniformly for all d>=7. At d=7 the possible multisets are exactly:

| N | epsilon | Moving ranks | Number of non-reflection branch elements |
|---:|---:|---|---:|
| 22 | 0 | 1^22 | 0 |
| 21 | 1 | 1^20, 2 | 1 |
| 20 | 2 | 1^19, 3 | 1 |
| 20 | 2 | 1^18, 2^2 | 2 |
| 19 | 3 | 1^18, 4 | 1 |
| 19 | 3 | 1^17, 2, 3 | 2 |
| 19 | 3 | 1^16, 2^3 | 3 |

This list is the partition enumeration of epsilon=0,1,2,3 and requires no group search.

## 2. The zero/one-exception cases reduce to reflection-generated groups

If no local monodromy has moving rank >1, the generated image is a reflection group. If exactly one does, write the product-one relation as A g B = 1, where A and B are products of rank-one reflections. Then

    g = A^{-1} B^{-1}

belongs to their subgroup. The whole image is again generated by reflections. No assumption that a group merely containing reflections must be reflection-generated is made.

The rank-seven irreducible finite reflection groups are the monomial family G(m,p,7), the symmetric reflection representation W(A7), and W(E7)=G36 in the standard Shephard–Todd numbering. The last two have rational character. Thus, **under the inherited monomial exclusion and the requirement that the character field is exactly K**, these four zero/one-exception rows are eliminated.

Classical classification source inspected as an indexed primary documentation list: Magma Handbook, “Construction of Finite Complex Reflection Groups”, https://docs.magma-maths.org/LieTheory/ReflectionGroups/create-group-refl-complex.html. It lists G36=W(E7) as the sole exceptional rank-seven group besides Sym(8). Bessis, arXiv:math/0610777v5, §2/Table 1, provides the compatible real/complex classification context. No full rereading of the Shephard–Todd classification proof is claimed.

## 3. Three surviving rank profiles (necessary, not sufficient)

    N=20:  1^18, 2, 2
    N=19:  1^17, 2, 3
    N=19:  1^16, 2, 2, 2

These are **not examples**. They merely identify the first profiles not excluded by the budget and reflection-generated classification argument. In particular, none supplies (L), a product-one generating tuple, a nonsplit form, an explicit Hodge filtration or period-map dominance.

For an actual fixed unitary representation and proposed class multiset, apply the reviewed locality theorem before building parabolic cohomology:

    [det h_par] = [prod_j a_j b_j],
    a_j = det(h_0|im(1-g_j)),  b_j = det((1-g_j)|im(1-g_j)).

The sign is + because dim_K H_par=8, hence n=4. Individual b_j need not be rational, so the norm-class operation applies to the **entire product** after compatibility with product-one is ensured. A split product rules the datum out for the nonsplit target without finding a braid component.
